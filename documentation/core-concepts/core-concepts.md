### The mental model

Data sources report activity about **assets**. Cyber MD evaluates that activity and creates **findings** and **alerts**. Analysts investigate alerts in **cases**. A workspace contains the team, sources, and cases.

Use findings to understand exposure. Use alerts to prioritize active risk.
